# Oddmash Mobile

Native-like interactions for the web.

Oddmash Mobile is a proposed React library for mobile web apps that need touch-friendly interactions without replacing their existing app shell, router or design system.

The first planned component is a draggable Bottom Sheet for tasks such as mobile filters, followed by Adaptive Dialog, Swipe Action and Pull to Refresh.

**Status:** Planning. No package or production-ready implementation is available yet.
